# applesorchard.in

Free apple orchard guide for Indian growers by Gujarat Bio Organics.

- Build: `python3 build.py` -> `dist/` (Cloudflare Pages: build command empty, output directory `dist`).
- Content: `content.py` (pillar, apple tree, varieties, rootstocks, pruning), `content2.py` (fertilizer + calculator, fruit quality, root rot, diseases, spray schedule, harvest, about), `content_local.py` (Hindi).
- Calculator: `src/calc.js`, tested with Node against the research worked examples.
- Facts only from `research-reference.md` (Dr. YSP UHF, SKUAST-K/J, ICAR-CITH, NHB, MoA&FW, USDA FAS, NIF, NITI Aayog, CIB&RC). Pesticides: active ingredient only, doses from official schedule and label.
